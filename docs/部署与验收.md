# 部署与验收清单

> 按顺序做，每步都有明确的"成功标志"，卡住就停在那一步排查。

## 0. 电脑端先跑通（不需要设备）

```powershell
powershell -File tools\run_server.ps1
```

看到这段就算成功：

```
小度大脑已启动
  设备连接地址 : http://192.168.x.x:8765/ws
  模型         : Qwen3.5-9B-MLX-4bit
  唤醒词       : 小度同学、你好小度同学
```

浏览器打开 `http://127.0.0.1:8765/` 能看到状态页；说一句话之后这里会出现对话记录。

**自测**（可选，验证整条链路）：

```powershell
python tools\sim_device.py
```

## 1. 刷机

用咸鱼那套 `小度X8-XDH-0F-A1-线刷V1.69NoRoot三方` 包。

| 步骤 | 成功标志 |
|---|---|
| 装 `UsbDk_1.0.22_x64.msi` | 装完不弹窗 |
| 设备关机（系统里关，别拔电源） | 屏幕全黑 |
| 按住 **音量+** 和 **电源** 不放，插 USB | 工具窗口出现 `Reconnecting to preloader` |
| 松手，拔线，立刻重新插上 | 出现分区列表 |
| 先读分区备份 `boot`/`system` | 两个 bin 大小和分区表一致 |
| 解锁 bootloader | 提示成功（会清数据） |
| 写 `system`（或按包内说明整体刷） | 进度条到 100% |
| 断电重启 | 开机出现当贝桌面 |

⚠️ 全程用笔记本电池，别断电、别碰线。
⚠️ `preloader` 是救砖的最后一道门，非必要不写。

## 2. 装 App

1. 把 `dist\XiaoduLink.apk` 拷到 U 盘（FAT32）
2. U 盘插到小度上
3. 打开 **ES 文件浏览器** → 找到 U 盘 → 点 APK → 安装
4. 安装时如果提示"未知来源"，允许一次

**成功标志**：应用列表里出现「小度同学」。

---

## 3. 首次配置

| 步骤 | 说明 |
|---|---|
| 打开「小度同学」 | 首次会弹麦克风权限，选允许 |
| 点「服务端地址」 | 填电脑上的地址，例如 `ws://<PC_IP>:8765/ws` |
| 点「接管麦克风」 | 按卡片提示，在屏幕顶部下拉点「禁用唤醒」 |

**成功标志**：状态环变成蓝色，文字显示「已连接电脑」。

## 4. 验收

对着小度说：

| 说什么 | 期望 |
|---|---|
| 「小度同学」 | 环变蓝，回一句「在」 |
| 「小度同学，今天几号」 | 环变黄（想一下）→ 变绿（说给你听），喇叭出声 |
| 紧接着说「那明天呢」 | **不用再喊唤醒词**，直接接上下文 |
| 「退出」 | 回到待机，环变灰 |

**必须检查的坑**：

- [ ] 播报时不会把自己的声音再识别一遍（TTS 播报期间闭麦）
- [ ] 放歌中喊「小度同学」也能唤醒
- [ ] 说完话 3 秒内出第一声
- [ ] 静置 10 分钟没有被系统杀掉（前台服务 + WakeLock）
- [ ] 断电重插，开机后自动恢复（BootReceiver）

---

## 5. 常见问题

| 现象 | 排查 |
|---|---|
| 一直「未连接」 | 电脑防火墙没放行 8765；或地址填错；`ping` 一下 |
| 连上了但说话没反应 | 原生小度还在抢麦，确认「禁用唤醒」已关 |
| 识别乱码 | 麦克风被别的应用占用；或说话太短（<0.7s 会被丢弃） |
| 声音断续 | 检查是否误开了 Breeze-TTS（`tts.engine: openai`），换回 edge |
| 模型不回复 | 服务端日志看 `LLM HTTP`，多半是 Mac 上模型被卸载了 |

---

## 6. 还原原生小度

把「禁用唤醒」重新打开，卸载「小度同学」即可。
刷机想完全还原：进 preloader 写回备份的 `system.bin` / `boot.bin`。
